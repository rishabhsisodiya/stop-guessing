Shape for `AGENTS.md`. Rules live in `SKILL.md`.

## What makes this file worth reading

- **Facts only**, each one with evidence in the repo. No aspirations, no universal coding
  advice (that is `develop/build-standards.md`).
- **Short.** Every skill loads this on every run. A fact that changes nobody's behavior is
  a recurring cost. If a line would not change what an agent does, cut it.
- **Commands verified.** Anything not actually run is marked `unverified` with the reason.
- **No placeholders.** Leave a section out rather than writing "TBD" or "n/a".

## `CLAUDE.md` pointer

A new `CLAUDE.md` is exactly this and nothing more:

```markdown
See [AGENTS.md](./AGENTS.md) for this project's stack, commands, structure and conventions.
```

An existing `CLAUDE.md` with real content keeps its content. Add the pointer line at the top
if it is not already there, and change nothing else.

## Ownership markers

Lines this skill may rewrite on a later run are the factual ones: versions, commands, paths.
Anything a human wrote is left alone forever. When a fact changes, the line is replaced and
the change is named in the report, never changed silently.
